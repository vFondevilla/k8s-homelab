# Fleet examples

Examples are non-reconciled references and experiments.

They remain outside every automatic Argo discovery pattern. They do not contain generated kubeconfigs or private credentials.

Current example groups:

- `cluster-api/` contains non-reconciled CAPK examples.
- `kubevirt/` contains opt-in virtual-machine examples.
- `tinkerbell/` contains opt-in bare-metal provisioning resources.

Do not add this directory to an Argo Application or ApplicationSet.
